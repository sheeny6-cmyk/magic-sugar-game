# 발레왕국 V2 — 1차 기반 리뉴얼 (2026-11-24)

## 목표
기존 직급 5단계와 플레이어 성장 Lv.1~100을 분리하고, 수업·공연·동작 숙련도를 하나의 지갑에 저장한다. 기존 이미지·의상·저장 데이터는 유지한다.

## 이번 브랜치
- 경험치: 수업의 정확도 및 첫 코스 보너스, 공연 정확도 및 최초 완주 보너스.
- 동작별 숙련도: 기본 박자·파드샤·그랑제떼·아라베스크·피루엣의 실제 성공 기록.
- 앨범: 첫 춤의 초대장과 라일락 왈츠. 작품별 횟수, 최고 등급, 정확도, 콤보.
- 힐링/일반 모드에서는 HP 때문에 강제 종료하지 않음. 챌린지만 HP 적용.
- GREAT 가중치 0.85, GOOD 0.65, PERFECT 1.0. 스튜디오 결과 UI 분리.
- 수업 2회 이후 왈츠가 정식 공연 보상을 지급. 이전에는 자유 연습. 왈츠는 현재 음식 효과를 소비하지 않음.
- 스튜디오·극장은 오디오 시작 기준으로 판정 시각을 계산. 기존 왈츠 시계를 유지.
- 기존 지갑의 직급·보상·코인·의상·수료 횟수 유지. 경험치는 과거 수업/공연 횟수로 1회 환산.
- 메인 화면의 추천 수업을 순환하고 미완주 공연을 먼저 안내한다.
- 새로 정산한 최근 공연 ID 128개를 보관해 동일 회차 중복 적립을 방지한다.

## 검증
`node town/tests/journey.test.cjs` 로 저장/정산 회귀 테스트 실행.
브라우저에서 모바일 터치, 실제 음악 지연, 의상별 이미지, 중단/재접속, 결과 화면 및 기존 상점 동작을 추가 검증해야 한다.

## 아직 미완료
- 실제 리듬 엔진 하나로 합치기 (현재 공통 시계 원칙과 지갑을 사용하나 조작 엔진은 별개).
- 준비·실행·착지 사이 동작 애니메이션 재제작, 홀드/연속 입력.
- 레벨별 실제 신규 콘텐츠 해금, 정령별 스토리 및 전문 안무, 새 공연 레퍼토리.
- 첫 5분 튜토리얼, 마을의 본격적인 시각적 발전, 상점 경제 재조정.
- 공개 배포 전 모든 페이지의 정적 자산 버전 통일 및 모바일 실기 테스트.

현재 브랜치는 검토용이며 main이나 기존 GitHub Pages 공개 버전을 변경하지 않는다.

## 2차 추가 — 정령 안무
라일락 왈츠 완주와 플레이어 Lv.4/5/6/8/10을 조건으로 에튜/아라/피루/샹즈/알레의 별도 안무를 해금한다. 기존 왈츠 원곡과 무대 자산을 공유하지만 차트는 각각 17/18/22/25/42노트이며 독립 공연 기록과 친밀도 보상을 저장한다. 새 음원이나 새 애니메이션이 만들어진 것은 아니다. 해금 전 정산 차단, 중복 정산, 친밀도 증가, 차트 범위/순서 검증을 수행했다.
