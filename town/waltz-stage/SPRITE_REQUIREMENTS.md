# 왈츠 스테이지 · 스프라이트 요구사항

이 문서는 `town/waltz-stage/` 시제품이 **지금 있는 정지 이미지로는 표현할 수 없어** 코드로 흉내 낸 부분과,
그 부분을 제대로 만들기 위해 필요한 스프라이트 시트 사양을 정리한 것입니다.

## 지금 쓰고 있는 자산

| 용도 | 파일 | 비고 |
| --- | --- | --- |
| 대기 · 예비 | `town/assets/dancers/lilac-ready.webp` | 정면 |
| 플리에 | `town/assets/dancers/lilac-plie.webp` | 정면 |
| 를르베 | `town/assets/dancers/lilac-releve.webp` | 정면 · 팔 올림 |
| 도약 대용 | `town/assets/dancers/lilac-arabesque.webp` | **측면(우향)** · 한 다리 뒤로 |
| 르베랑스 | `town/assets/dancers/lilac-curtsy.webp` | 정면 |
| 정령(에튀) | `kingdom/assets/av_etu.webp` | 투명 PNG 계열 |
| 고양이 · 허들 · 균형대 | (없음) | 캔버스 벡터로 직접 그림 |

정지 이미지 6장을 캔버스에서 위치·확대·회전·가로 눌림으로 변형해 **예비 → 도약 → 착지**의 궤적을 만듭니다.
궤적 자체는 마스터 클록(곡 시각)에 맞춰 계산되므로 음악과는 어긋나지 않지만,
**몸의 형태는 프레임 사이에서 변하지 않습니다.** 그래서 다음 네 동작이 "동작"이 아니라 "포즈 전환"으로 보입니다.

## 지금 코드로 흉내 내는 방식과 한계

| 동작 | 현재 구현 | 한계 |
| --- | --- | --- |
| 파드샤(고양이 넘기) | 플리에 → 아라베스크(측면) 자세를 포물선으로 띄움 + 잔상 3장 | 도약 중 두 다리가 접히지 않음. 정점에서 다리가 뒤로 뻗은 채라 "뛰어넘기"보다 "들어 올려지기"로 보임 |
| 그랑제떼(허들 넘기) | 같은 아라베스크 자세를 더 크게(108px) 띄우고 11° 기울임 | 실제 그랑제떼의 180° 다리 벌림이 없음 |
| 아라베스크(균형대) | 아라베스크 자세를 34px 올려 균형대 위에 세움 | 올라서는 동작·내려서는 동작이 없음(순간 이동) |
| 피루엣(회전) | 를르베 자세를 `scaleX = cos(θ)`로 눌러 90°에서 종이처럼 얇아지게 + 잔상 6장 + 허리 높이 회전 호 + 발끝 빛 + 반짝임 | **정면 그림이라 등·옆모습이 없어** 한 바퀴 도는 느낌이 약함. 2바퀴(720°)는 더 약함 |

이 네 가지는 플레이에 지장을 주지는 않지만(판정·박자·궤적은 모두 정확), "정말 뛰어넘는다"는 손맛은 프레임이 있어야 완성됩니다.

## 필요한 스프라이트 시트 (우선순위 순)

### 공통 사양

- **뷰**: 측면 3/4, 오른쪽을 바라보는 방향(장애물이 오른쪽에서 오므로). 정면 시트와 별도로 제작.
- **기준선**: 발바닥이 이미지 아래쪽 `y = H`에 닿도록 통일. 캐릭터 키 `H = 500px`(2배 해상도 1000px 권장).
- **가로 중심**: 모든 프레임에서 몸통 중심 `x = W/2`. 도약 중 이동은 코드가 처리하므로 시트 안에서 캐릭터를 좌우로 옮기지 않습니다.
- **투명 배경** PNG 또는 WebP(알파). 프레임 이름 규칙: `lilac-<동작>-<번호>.webp`.
- **프레임 레이트**: 12fps면 충분(현재 코드는 시간 기반으로 프레임을 고르므로 12fps로도 부드럽습니다).
- 의상·머리·얼굴은 기존 `lilac-*` 세트와 동일해야 합니다(같은 캐릭터로 보이도록).

### 1. 파드샤 `lilac-pasdechat-1..6.webp` (필수)

| # | 자세 |
| --- | --- |
| 1 | 준비 — 플리에, 팔 5번 자세 |
| 2 | 밀어올리기 — 를르베, 팔이 위로 열림, 발끝이 바닥에서 막 떨어짐 |
| 3 | 이륙 — 두 다리 모아 45°, 몸이 살짝 젖혀짐 |
| 4 | 정점 — **두 다리 접힘(뒤꿈치가 엉덩이 쪽)**, 팔 2번, 고양이 머리보다 확실히 높음 |
| 5 | 하강 — 다리 펴며 착지 준비, 팔 내려옴 |
| 6 | 착지 — 플리에, 시선 앞 |

길이 0.54초(코드의 비행 구간과 동일). 정점이 3~4번.

### 2. 그랑제떼 `lilac-grandjete-1..7.webp` (필수)

| # | 자세 |
| --- | --- |
| 1 | 준비 — 플리에, 팔 뒤로 |
| 2 | 도움닫기 — 앞발 텐뒤, 상체 기울기 |
| 3 | 이륙 — 밀어올리며 앞다리 들기 |

### 3. 균형대 아라베스크 `lilac-beambar-1..5.webp` (권장)

| # | 자세 |
| --- | --- |
| 1 | 오르기 — 두 발 모아 균형대 위로 살짝 점프 |
| 2 | 균형 A — 아라베스크, 뒤 다리 45°, 팔 2번 (현재 `lilac-arabesque`로 대체 중) |

| # | 각도 | 비고 |

| 1 | 0° (정면) | 팔 5번, 파세(발목 붙임), 를르베 |
| 2 | 45° | |

| 4 | 135° | |
| 5 | 180° (뒤) | 머리·등이 보이는 프레임 |

### 5. (선택) 착지 먼지·발끝 효과

착지 먼지, 발끝 스포트라이트, 회전 호는 지금도 캔버스로 그리고 있어 **필요 없습니다.**

## 제작 시 주의

- 네 동작 모두 **발끝 위치가 프레임마다 일정 간격으로 올라가야** 코드의 포물선과 어긋나지 않습니다.
  코드는 발바닥 기준선을 `groundY - 높이`로 옮기며 그리므로, 시트 안에서 캐릭터가 위아래로 미리 움직이면 궤적이 두 번 적용됩니다.
- 고양이·허들은 지금 벡터로 그린 것이 의도적으로 단순합니다. 실제 프롭 이미지를 넣을 경우
  `groundY`에 발이 닿는 기준(고양이 높이 34px, 허들 46px, 균형대 상판 40px)만 지키면 됩니다.
