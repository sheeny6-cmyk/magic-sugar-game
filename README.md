## ☕ 슈가 발레 카페 (`cafe/`)

발레리나 손님들의 주문을 받아 75초 동안 라떼를 만들고 **컵을 쓱쓱 문질러 섞어** 서빙하는 미니게임입니다.

- 플레이: https://sheeny6-cmyk.github.io/magic-sugar-game/cafe/
- 메뉴 6종: 아이스 아메리카노 · 아라베스크 밀크 · 바뜨망 프로틴 라떼 · 턴아웃 라떼 · 피루엣 라떼 · 포인 말차 라떼
  (셔플 백으로 6종이 골고루, 같은 메뉴가 연달아 나오지 않아요)
- 재료 9종을 순서 상관없이 톡톡 담고, 컵 위를 손가락으로 문질러(또는 꾹 눌러) 게이지를 100%까지 채운 뒤 [서빙하기]
- 성공하면 손님에게 벌어진 마법 반응 카드가, 엉뚱한 음료를 내면 재료 조합별 사고 카드가 뜹니다 (탭하면 바로 다음 손님)
- 가끔 `깜짝 손님`(엄격한 원장님·공연 5분 전 주역·토슈즈 첫날 취발러)이 와서 특별 보너스를 줍니다
- 영업이 끝나면 오늘의 기록으로 정해지는 **`오늘의 마법 바리스타` 칭호**와 **오늘의 카페 일지** 한 줄
- [📸 결과 공유 / 이미지 저장]으로 1080×1350 결과 카드를 만들어 공유하거나 PNG로 저장(공유 미지원 시 저장 + 문구 복사)
- 검증: `cafe/tools/v2_check.py` (360×640·390×844 레이아웃, 섞기→서빙→반응→결과→공유 전 흐름)

## 🩰 발레 왕국 마을 (`town/`)

슈가 공주가 사는 꿈속 마을. 코인을 벌고 → 레오타드를 사고 → 학원에 다니고 → 무대를 준비하는 작은 생활 루프입니다.

- 마을: https://sheeny6-cmyk.github.io/magic-sugar-game/town/?v=20261121a
- `🍢 발레 분식집` (`town/snack/`): 0kcal 꿈속 심야 분식집. 아라·알레·에튜·상즈·피루 다섯 정령과 슈가 공주가 발레 고민을 들고 찾아오면, 사진 속 마법 분식 8종 중 딱 맞는 메뉴(콜라 조합 포함)를 골라 서빙합니다. 맞히면 실제 음식 사진과 함께 마법 발동 리액션 + 스탯 + 코인, 틀리면 정답을 알려 줘요. 원본 메뉴판 일러스트 + 음식 사진 8장은 `메뉴 도감`에서 언제든 볼 수 있습니다.
- `👗 드레스룸` (`town/dressroom/`): 코인으로 레오타드 5종 구매·착용(기본 0 · 라일락 150 · 백조 300 · 블랙스완 600 · 마법 슈가 드레스 1,000).
- `🩰 발레 스튜디오` (`town/studio/`): 수강료 100·150·250코인으로 바 워크·센터 워크·작품반 수업. 입장할 때 드레스룸에서 입은 옷이 출석 카드에 표시되고, 수업을 마치면 스탯·출석 도장이 쌓입니다.
- `🎭 무대` (`town/stage/`): 수업 5번(스튜디오 Lv.3)을 채우면 열리는 첫 공연 「잠자는 숲속의 슈가」 목표. 공연은 다음 업데이트.
- 지갑·스탯·옷장은 `localStorage`(`sugartown.v1`)에 저장되고, `☕ 슈가 발레 카페`는 마을에서 그대로 이어집니다.
- 검증: `town/tools/verify_local.py` (360×640·390×844 오버플로우 0, 분식집 서빙→코인/스탯, 드레스룸 구매→착용, 스튜디오 수업→레벨/무대 해금)
